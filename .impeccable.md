## Design Context

### Users

People investigating a crowded disk, including developers with Git repositories, build outputs, caches, and CLI tools. They need useful investigation and clear control over individual cleanup decisions. A standalone desktop application must explain evidence without requiring the user to understand its internals.

### Brand Personality

Confirmed visual direction: a desktop utility with a rich storage map, more expressive and colorful like a visual disk explorer. Keep controls and evidence precise; let meaningful category colors and spatial exploration supply expression. No separate brand identity has been approved.

### Aesthetic Direction

A spatial storage explorer linked to a rigorous plan editor. Expressive, readable category fills concentrated in the map; generous space around it; compact desktop chrome; contextual detail. Support both system appearances, screen readers, keyboard operation, and reduced motion. The user has not specified reference applications, brand colors, or a preferred theme. The desktop-utility / colorful-disk-explorer combination was explicitly selected by the user. Reference applications and exact palette remain unspecified.

### Design Principles

1. Make storage and consequences visible through meaningful geometry and labels.
2. Keep occupied size, candidate savings, selected actions, and actual recovered space distinct.
3. Link map, list, plan, and evidence through a stable selection.
4. Every executable decision is editable and explicitly reviewed; blocked actions stay blocked.
5. Share the product design across operating systems while respecting platform behavior and accessibility.
