# Implementation forecast after the first native lifecycle

This forecast uses verified work batches rather than calendar weeks. A batch has one bounded behavior or proof, a coordinator review, relevant checks, and a durable checkpoint. External CI, signing credentials and human studies have separate waiting time. The ranges below are planning estimates, not delivery promises or milestone-completion evidence.

## Observed effort

The M1A feature branch began from the M0 contract checkpoint committed at 23:17 local time on 2026-10-31. By approximately 00:02 on 2026-11-01, the persistent editor and the native disposable stage/restart/restore interaction had been demonstrated. Several implementation streams ran concurrently through Luna, with coordinator integration and native testing. This elapsed interval is not a person-hour measurement and cannot be extrapolated to a public release.

The work required two reviewable implementation checkpoints and several corrective review passes. The main surprises were ownership during recovery, SQLite schema ownership, path derivation from stored records, uncertainty after a move, and interface refresh/eligibility behavior. Native confirmation and the smaller debug build were feasible locally. The first complete interaction is therefore demonstrated, while broad file support and production permission/distribution remain materially larger work.

The range is deliberately broad: 42–75 further batches including M1A closeout. Some independent proof work can overlap, but dependent lifecycle and review gates cannot be skipped. Human study recruitment, unavailable CI and signing setup can dominate elapsed time regardless of implementation speed. No calendar release date is justified yet.

The macOS-first MVP scope remains unchanged. Later repository preservation/housekeeping, near duplicates, uninstall integrations and supported Windows/Linux releases remain the post-MVP tracks in ROADMAP.md. Passing a portable unit test does not move those releases into the MVP or establish native operation support.
