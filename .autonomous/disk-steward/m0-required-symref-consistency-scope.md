# M0 consistency of present symbolic-ref claims

Inactive manifest capture rejects contradictions within the supplied snapshot: every symbolic link to a present entry must match its object ID and kind, and chains among present entries must terminate without cycles. Missing targets remain external caller claims. No heap graph allocation; fixed 1024-byte state and 1024-usize path arrays (9 KiB on 64-bit targets). Memoized traversal processes every entry and present edge once with binary search in canonical entries; O(N log N) lookups and cooperative traversal/completion controls. Existing entry/name/aggregate bounds remain unchanged. Digest format stays v2.

Tests cover valid and externally terminating chains, two/three-node cycles, OID/kind mismatch and the maximum 1024-entry chain/cycle. An independent repeated-walk oracle checks all 1296 four-entry direct/external/present-link graphs, including merged tails and cycles reached away from the start. Existing native HEAD-switch/detachment/private-TLS flow remains exercised.
