# M0: bound fixed-worker shutdown waits

Build on PR103 with main as eventual integration baseline. Fixed own-executable probe shutdown currently calls blocking Child::wait and JoinHandle::join even when kill/reap failed. Replace unbounded waits with finite monotonic deadline/poll-count guarded try_wait and reader is_finished checks; join only after completion was observed. Apply consistently to the worker probe's fixed-child launch paths and error finalizers.

Preserve stop/reap attempts after query errors and kill/exit races. A known reaped exit is valid; failure to confirm either process shutdown or reader completion must return explicit uncertainty and withhold StopReceipt/worker-stopped/cleanup claims. Dropping an unconfirmed reader handle may detach it: report that limitation honestly rather than claim it joined. No generic execution, new CLI modes, descendant-tree/process-group authority, reservation release, user-file removal, source-repository access or renderer capability. Fixed child identity only.

Use bounded helper tests with injectable probe/clock/sleep seams where appropriate, plus controlled task-owned threads released and observed finished by the test when testing reader timeout. No indefinite test helper or orphaned real child. Existing fixed-child supervision/receipt/accounting tests must pass. Root reviews implementation before builds; no overlapping builds; respect2GiBreserve. Validate worker native tests/strict Clippy/fmt/version; record ignored helpers/platform limits. Bounds cover polling/completion checks, not a hard deadline on noninterruptible OS calls, production isolation, power loss, or M0 completion. Version0.0.x/no releases.

Follow-up validation: factor only the existing stop/query/confirm policy through a private generic operation seam; the production entry point still accepts only its owned Child and uses the same fixed operations. Deterministic scripted failures must prove that a query error cannot skip the kill/confirm attempt, a kill error cannot defeat independently confirmed natural exit, already-reaped status skips further operations, and missing exit confirmation preserves all available error reasons. No test fakes create process-stop receipts or expand public execution authority.
