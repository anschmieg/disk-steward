# M0 native Git delta decoder interoperability

Close a validation gap between synthetic delta vectors and the existing real-Git ordinary-object fixture. Use only task-owned private roots, fixed /usr/bin/git with cleared environment/no global or system configuration/hooks/templates, and existing bounded command input/output/deadlines. Create two bounded deterministic related blob contents, ask native Git to produce packs with offset and reference deltas, and require actual delta entry kinds rather than accepting full-object fallback.

Decode each bounded pack with the inactive decoder; compare canonical IDs, kinds and exact reconstructed bytes to the source fixture independently of entry order. Import into a fresh strict native receiver and compare exact bytes there too. Existing 512-byte command-input bound remains unchanged. Supervise the complete fixture as an exactly selected environment-cleared child with a 30-second parent limit, bounded completion marker, kill/reap/reader join on failure. Fixtures are not user repositories; no network, credential or renderer capability is introduced.

Branch test/m0-native-git-delta-decode starts at PR86 427a84e, main eventual integration baseline. Success proves these two small native encoder outputs on tested Git/platform only, not arbitrary delta depth, forward/external bases, full fsck, public/private GitHub authentication, RSS/OS interruption guarantees, local preservation or cleanup eligibility. Version remains 0.0.17/no releases; fresh current-head CI and no blocking findings required before main integration.
