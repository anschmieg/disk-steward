# M2A scoped folder navigation

Build from durable PR111 c06cd8e with main as eventual integration baseline. Make the live read-only immediate-entry explorer useful through explicit folder drill-down and Back navigation. Backend retains one native-selected directory descriptor session and bounded stack (16 levels); renderer sends only exact observation/entry IDs, never paths. Hold descriptors and validate nofollow opened child identity/device against observed metadata; reject stale observations, links, changed/moved entries, cross-device directories and named package/library boundaries. Each navigation creates a fresh opaque observation ID, not cleanup authority. Serial native ownership and state mutex protect transitions; failed navigation leaves previous snapshot/state intact. Native picker cancellation retains previous session.

All snapshots remain bounded to512 immediate entries/two-second cooperative checks; metadata-only/no contents/automatic recursion/cleanup. Breadcrumb labels are display-only and bounded, no absolute paths returned/persisted. No durable/resumable scan or cloud hydration support claim. Tests use disposable fixtures for navigation/back/stale IDs/symlink and directory replacement/mount-device refusal/boundary folders/depth limits. Root reviews and serially validates native tests/Clippy/fmt/frontend tests/build/format/version; no release/M2A completion/MVP acceptance.

The same bounded list gains a local name filter and subtle logical-size background bars. Their denominator stays the full observation's per-name regular-file logical sum when filtering or sorting; folders and unsupported entries stay unknown. This is neither allocated-space geometry nor candidate/recoverable-space accounting.
